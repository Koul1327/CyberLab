# CyberLab

Моя маленькая учебная лаборатория веб-безопасности на Flask для резюме)))

Каждый модуль содержит уязвимую реализацию, исправленную версию, тесты и объяснение проблемы

| Модуль | Уязвимость | Кол-во тестов
| --- | --- | --- |
| [01. Обход аутентификации](labs/auth_bypass/README.md) | Проверка пароля, создание сессии и назначение роли | 6 тестов |
| [02. IDOR - доступ к чужим заметкам](labs/idor/README.md) | Проверка владельца обьекта и разграничение доступа | 5 тестов |

## Лаборатории

В планах 10 модулей с привязкой к категориям OWASP

## Подготовка

Вам потребуется Python 3.12. Команды выполняются из корня проекта

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install Flask pytest
```

## Запуск лабораторий

Каждый модуль содержит две версии:

- `vulnerable` — приложение с уязвимостью
- `fixed` — версия с исправлением этой уязвимости.

Команды выполняются из корня проекта с активным окружением:

```bash
source .venv/bin/activate
```

Выбери нужную тебе лабораторию и следуй её инструкции:

- [Обход аутентификации](labs/auth_bypass/README.md)
- [IDOR — доступ к чужим заметкам](labs/idor/README.md)

В инструкции каждого модуля указаны команды запуска, адреса, аккаунты и воспроизведения.

Версия `fixed` исправляет проблему конкретного модуля!!!


## Проверка

```bash
python -m pytest labs/ -q
```

Тесты проверяют обход аутентификации, права на адмиyre и доступ к своим и чужим заметкам
