## Подготовка и запуск

Все команды выполняются из корня репозитория CyberLab

Перед первым запуском:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install Flask pytest
```

При следующих запусках достаточно активировать окружение:

```bash
source .venv/bin/activate
```

### Уязвимая версия

```bash
python -m flask --app labs.idor.vulnerable.app run --host 127.0.0.1 --port 5002
```

Страница входа: http://127.0.0.1:5002/login

### Исправленная версия

В другом терминале из корня проекта активируй окружение и запусти:

```bash
source .venv/bin/activate
python -m flask --app labs.idor.fixed.app run --host 127.0.0.1 --port 5003
```

Страница входа: http://127.0.0.1:5003/login

### Учебный аккаунт

В обеих версиях:

| Пользователь | Пароль | Роль |
|---|---|---|
| Alex | alex-lab-password | user |

### Проверка вручную

Войди как Alex через `/login` выбранной версии
Затем открой следующие пути на том же адресе и порту:

| Запрос | Уязвимая версия | Исправленная версия |
|---|---|---|
| `/notes/1` — заметка Alex | 200, заметка доступна | 200, заметка доступна |
| `/notes/2` — заметка Bob | 200, чужая заметка раскрыта | 403, доступ запрещён |
| `/notes/999` — несуществующая заметка | 404 | 404 |

Без входа запрос заметки возвращает 401

### Запуск тестов

```bash
python -m pytest labs/idor/tests/ -q
```

Ожидаем: 5 passed

Для остановки сервера нажми Ctrl+C
